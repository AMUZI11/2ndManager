Buat View Kalkulasi Kuota Efektif ('v_organization_effective_quotas'):

SQL
CREATE OR REPLACE VIEW v_organization_effective_quotas AS
SELECT 
  os.organization_id,
  os.current_tier,
  os.expires_at,
  os.is_active,
  -- Basis Kuota Cabang berdasarkan Tier
  (CASE 
    WHEN os.current_tier = 'JURAGAN_CABANG' OR os.current_tier = 'EKSEKUTIF' THEN 3
    ELSE 1 
  END + os.extra_branches_quota) AS max_allowed_branches,

  -- Basis Kuota Kasir berdasarkan Tier
  (CASE 
    WHEN os.current_tier = 'RINTISAN' OR os.current_tier = 'MAGANG' THEN 1
    WHEN os.current_tier = 'MANDIRI' OR os.current_tier = 'SUPERVISOR' THEN 2
    WHEN os.current_tier = 'USAHA_BERKEMBANG' OR os.current_tier = 'MANAJER' THEN 4
    ELSE 8 
  END + os.extra_cashiers_quota) AS max_allowed_cashiers,

  -- Jumlah Entitas Aktif Saat Ini
  (SELECT COUNT(*) FROM branches b WHERE b.organization_id = os.organization_id AND b.is_active = TRUE) AS current_active_branches,
  (SELECT COUNT(*) FROM user_shops us 
   JOIN profiles p ON p.id = us.user_id 
   WHERE p.organization_id = os.organization_id AND p.role = 'CASHIER' AND p.is_active = TRUE) AS current_active_cashiers
FROM organization_subscriptions os;

2. LOGIKA PRORASI BIAYA & BACKEND API (NEXT.JS APP ROUTER)
Formula Penyelarasan Masa Aktif (Co-Termination Proration):

Standar Harga Dasar Bulanan (30 hari):

1 Slot Cabang = Rp 100.000 / bulan.

1 Slot Kasir  = Rp 20.000 / bulan.

Perhitungan Prorasi jika Dibeli di Tengah Siklus Langganan:

sisa_hari = CEIL((expires_at - NOW()) dalam hari).

Jika sisa_hari <= 0 (langganan kadaluarsa), hitung tarif 30 hari penuh.

Jika sisa_hari > 0:

harga_cabang = (100000 / 30) * sisa_hari (dibulatkan ke ribuan terdekat).

harga_kasir  = (20000 / 30) * sisa_hari (dibulatkan ke ribuan terdekat).

Endpoint Kalkulasi & Preview Add-on ('src/app/api/v1/billing/addons/calculate/route.js'):
